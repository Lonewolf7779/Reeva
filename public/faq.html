Frequently Asked Questions

Honest answers regarding Reeva's architecture, extraction modes, and privacy model.

1. What is Reeva?
Reeva is an open-source, minimalist web utility designed to allow users to retrieve, preview, and save publicly accessible video media from supported platforms for personal archival and educational purposes.
2. How does Reeva work?
When you submit a URL, Reeva's hardened backend queries official platform syndication and metadata endpoints using strict TLS connections. It parses available stream manifests, verifies media magic bytes and codecs, and streams the verified audio/video binary directly to your browser.
3. Which platforms are supported?
Reeva provides verified extraction for YouTube, Twitter/X, Pinterest, and generic public web MP4/WebM files. It also integrates TikTok, Instagram, and Facebook with public extraction and automatic official sandboxed embed fallbacks.
4. Why might a URL fail to download?
URLs can fail if the original post has been deleted, set to private, protected by login credentials, or geo-restricted. Failures also occur if the link is malformed or points to an unsupported domain blocked by our security filters.
5. Why are some videos embed-only?
Certain platforms (such as Meta and ByteDance) enforce strict terms or edge challenges that restrict unauthenticated binary file scraping. To respect platform terms while still serving the user, Reeva automatically renders the official sandboxed player instead of failing silently.
6. Does Reeva host or store uploaded videos?
No. Reeva never hosts, stores, or re-broadcasts media. It functions purely as a transient gateway. Content is either streamed ephemerally or displayed via the platform's official embed player.
7. Does Reeva retain downloaded files on the server?
No. Any temporary files written to server scratch storage (e.g., during format merging) are assigned a short 10-minute lifespan. An automated daemon purges all expired artifacts from disk every 60 seconds.
8. Can users download private content?
No. Reeva does not accept credentials, bypass access controls, or crack paywalls. It can only process content that is publicly accessible to any unauthenticated visitor on the open web.
9. What permissions should I have before downloading?
You should only download content that you own, content published under permissive licenses (such as Creative Commons), or content you have explicit legal permission to archive for personal, educational, or fair-use purposes.
10. Is Reeva affiliated with social networks?
No. Reeva is an independent open-source project and is not affiliated, sponsored, or endorsed by YouTube, Meta, ByteDance, X Corp, or Pinterest.
